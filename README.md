# Blue Ocarina Songbook

Create a very lightweight mobile-friendly web app (doesn't need a framework) that would let me play songs when playing the Zelda game "Ocarina of time". It should feel cohesive with the Ocarina of time experience of the game, featuring hte blue ocarina and visuals, styling and fonts that are related to Zelda and used in branading.
